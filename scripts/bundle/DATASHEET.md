# DegradX benchmark: generated units with attribution ground truth

Multivariate degradation sequences generated by DegradX, a generator fitted to public battery-degradation datasets. Each
sequence carries a regression target that is an exact additive function of its observations. The contribution of every
observation to the target is therefore known by construction. Use it to test whether an attribution method recovers the
true contributions of a time-series regression model.

Code, fitted parameters, trained models and results: <https://github.com/Myroslav437/DegradX>.

## Data

`<PROFILE>/seed<g>.npz` stores the exact decomposition of every unit. The positions of all units are concatenated, and
unit `i` occupies rows `offsets[i]:offsets[i+1]`.

| array | shape | meaning |
|---|---|---|
| `unit_index`, `source_unit`, `split`, `T` | (N,) | unit index, the measured unit whose parameters it resampled, split, length |
| `offsets` | (N+1,) | row offsets into the per-position arrays |
| `z` | (ΣT,) | degradation state: 0 pristine, 1 at EOL |
| `m` | (ΣT, C) | mean component (0 on the null channels) |
| `p` | (ΣT,) | summed inserted patterns, on the capacity channel only |
| `eps` | (ΣT, C) | noise; on the null channels, their whole value |

The observation is `x = m + eps`, plus `p` on the capacity channel. The units of `x` are those of the measured channels
(capacity in Ah, charge time in minutes, voltage in V, internal resistance in Ω, temperature in °C). The two null
channels carry no information about the target. `null_flat` is AR(1) noise. `null_permuted` holds measured charge-time
readings, drawn independently of position.

## Target and ground truth

A window holds `L = 24` consecutive positions ending at position `t`, with rows ordered oldest first. With window weights
`w[u, c] = pi[u] * kappa[c]`:

```
graded   = w * (m - x0)          dense field: the mean component contributes at every position
sparse   = w * p                 non-zero only on the positions and channel of inserted patterns
phi_star = graded + sparse       attribution ground truth; sum(phi_star) == y exactly
y        = sum(phi_star)         regression target (the training target of the models)
g(x)     = sum(w * (x - x0))     reference model, a linear model with exact attribution w * (x - x0); g(x) - y = sum(w * eps)
R        = T - t                 remaining useful life at the window end
```

- `kappa[c] = beta_c / (phi_c(1) - phi_c(0))` on the weighted channels, where `phi_c` is the profile's channel mapping
  and `beta` gives each weighted channel an equal share. `kappa` is 0 on the other channels.
- `x0` is the pristine reference point: each channel's value at `z = 0`, and the median of the null pool for
  `null_permuted`. The window filled with `x0` is the declared attribution baseline. For another baseline `b`, the
  ground truth is `w * (m + p - b)`.
- `pi` is the position profile. `recency` halves the weight every 6 positions back from the window end and is the primary
  weighting. `uniform` gives every position the same weight and is the sensitivity weighting.

```python
from degradx_benchmark import load

b = load("FORM", seed=0)                       # run from this directory, or pass root=<bundle path>
for unit in b.units("train"):
    w = b.windows(unit, "recency")             # every full window of the unit
    X, y = w["x"], w["y"]                      # (n, L, C), (n,)
test_windows = b.evaluation_windows()          # [(unit, t), ...] scored in the paper
w = b.windows(test_windows[0][0], "recency", ends=[test_windows[0][1]])
w["phi_star"][0]                               # (L, C) ground truth for that window
```

## Scoring an attribution method

Explain a model on a window `x` and on its pattern-free counterpart `x_pattern_free`, giving maps `A` and `A_pf` of
shape (L, C). The paper scores them with `scores.py`:

| score | call | perfect |
|---|---|---|
| rank agreement | `rank_agreement(A_pf, graded)` (Spearman over all cells) | 1 |
| channel allocation error | `channel_allocation_error(A_pf, graded)` (total variation between per-channel shares) | 0 |
| temporal profile error | `temporal_profile_error(A_pf, graded, weighted_idx)[0]` (1-Wasserstein over positions) | 0 |
| zero-weight mass | `zero_weight_mass(A, zero_idx)` (share of the map on channels with `kappa == 0`) | 0 |
| paired retrieval (FORM only) | `retrieval_ap(A - A_pf, sparse != 0)` (average precision) | 1 |

Here `weighted_idx` and `zero_idx` are the channel indices with `kappa != 0` and `kappa == 0`. Scores are averaged per
test unit and then over units. The reference values reported in the paper use the windows in
`<PROFILE>/evaluation_windows.csv` from the pristine baseline `x0`. On the reference model `g`, a faithful method
reproduces `w * (x - x0)` exactly. That exact attribution includes the noise term `w * eps`, so it scores below perfect
against `graded` on rank agreement, allocation and temporal error. This ceiling is reported with the reference values
(for FORM under recency weighting, about 0.85 / 0.13 / 0.63; paired retrieval 1).

The repository holds the trained models (a ten-member LSTM ensemble per profile and weighting, trained on seed 0) and
the reference values of Integrated Gradients, feature occlusion and TimeSHAP.

## Provenance

The bundle is written by `scripts/export_benchmark.py` from the generator's output for the declared seeds (base seed
20260915). `degradx_benchmark.py` was checked against the generator's own target code on every window of every unit
(exact equality; the count per seed is in `manifest.json`). Regenerating the units with the repository code and seeds
gives the same arrays.
